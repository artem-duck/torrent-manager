# История версий

## v1.2.0 — Telegram-бот и уведомление о скачивании

### Что нового

- Встроенный Telegram-бот: токен указывается в веб-настройках, отдельный сервис не нужен.
- Фильтры в боте (`/settings`): все логи, ошибки, замена торрента, добавление в qBittorrent, **скачивание 100%**.
- Когда после замены раздачи qBittorrent докачивает файл до конца, бот пишет, что серия готова.
- Обход Cloudflare через сессии FlareSolverr и обычные HTTP-запросы по cookies.
- Chrome FlareSolverr гасится после проверки, временные файлы в RAM (`tmpfs`), лимиты памяти — меньше нагрузка на диск.

### Как обновиться

```bash
docker compose up -d --build
```

В настройках сайта вставьте токен бота, включите уведомления, напишите боту `/start`.
